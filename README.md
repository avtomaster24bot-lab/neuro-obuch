# Нейро Обуч — школа нейросетей

Сайт-презентация онлайн-школы нейросетей в режиме **листа ожидания**: курсы пока не продаются, предоплату не берём.

**Воронка:** бесплатный урок «Формула сильного промпта» (`/urok/formula-prompta/`) → сообщение «СТАРТ» в Telegram [@GrifRift555](https://t.me/GrifRift555?text=%D0%A1%D0%A2%D0%90%D0%A0%D0%A2) → уведомление, когда откроется набор.

Тем, кто пишет «СТАРТ», задаём один вопрос: **«Какую задачу ты хочешь научиться решать с нейросетью?»** Ответы определяют первые уроки пилота.

**Пилот:** небольшой практикум «Нейросети с нуля», где каждый участник решает с ИИ свою реальную рабочую задачу. Остальные 6 направлений — «Следующие программы, откроем по запросам».

**Программа пилота (14 уроков, 2 недели):** 1) Как работает ИИ — уроки 1–4; 2) Запросы, которые можно повторить — 5–8 (урок 5 = бесплатный «Формула сильного промпта»); 3) Реальные задачи — 9–12; 4) Проверка и безопасность — 13–14. Формат: короткие текстовые уроки, разборы, схемы и практические задания в закрытом Telegram-канале с оглавлением; аудиоверсия есть у бесплатного урока.

> Тексты платных уроков в этот публичный репозиторий **не кладём** — на сайте только названия и описание программы.

**Сайт:** https://avtomaster24bot-lab.github.io/neuro-obuch/

## Как добавить новинку в «Новое каждый день»

Откройте `data/feed.json` и добавьте объект **в начало** массива `items` (лента сортируется по дате, сборка не нужна):

```json
{
  "date": "2026-11-24",
  "title": "Короткий заголовок новинки",
  "tag": "Видео",
  "text": "Что появилось — 2–3 предложения.",
  "how": "Как применить у себя.",
  "source_name": "Блог компании",
  "source_url": "https://ссылка-на-первоисточник",
  "video_url": "https://youtube.com/shorts/... (необязательно)",
  "region": "Ограничения по странам (необязательно)"
}
```

Теги: `Текст`, `Картинки`, `Видео`, `Голос`, `Бизнес`, `Агенты`, `Код`. Если указать `video_url`, на карточке появится кнопка «Смотреть видео» — так ежедневные ролики из YouTube/Shorts/Rutube/VK попадают на сайт. Всегда указывайте первоисточник.

Можно править прямо на GitHub: открыть файл → карандаш ✏️ → Commit. Через 1–2 минуты сайт обновится.

## Как поменять ссылки

Всё в одном файле `config.js`:

- `WAITLIST_URL` — кнопки «Написать «СТАРТ»»: `https://t.me/GrifRift555?text=%D0%A1%D0%A2%D0%90%D0%A0%D0%A2` (чат открывается с готовым словом «СТАРТ»);
- `CONTACT_URL` — «Написать нам» / «Задать вопрос»: `https://t.me/GrifRift555`;
- `TELEGRAM_CHANNEL_URL` — подписка, гайды, ежедневная лента: `https://t.me/PostFlowFactory`;
- `YOUTUBE_URL`, `INSTAGRAM_URL`, `TIKTOK_URL`, `VK_URL` — пустые иконки скрыты.

После правки `config.js` запустите `python3 _src/build.py`: ссылки также вшиваются прямо в HTML (работают даже без JavaScript).

Кнопок оплаты, цен и тарифов на сайте сейчас нет. Когда откроете продажи — добавьте их в `_src/build.py` (функции `course`, `catalog`) и ссылку оплаты в `config.js`.

## Как поменять курсы, цены, тексты

1. Правите `_src/data.py` (тексты курсов, модули, FAQ).
2. Запускаете `python3 _src/build.py` — страницы пересоберутся.
3. Аудио: правите `_src/audio/*.txt`, затем
   `edge-tts --voice ru-RU-SvetlanaNeural -f _src/audio/prezentaciya.txt --write-media assets/audio/prezentaciya.mp3`
4. PDF гайдов: `python3 _src/tools.py pdf` (нужен `pip install playwright && playwright install chromium`).

## Что осталось заполнить

- Цены и оплата — появятся, когда откроется набор (сейчас лист ожидания).
- Отзывы — добавим после пилота, только настоящие.
- Оферта и условия участия — до старта набора.

Картинки курсов сгенерированы ИИ, схемы в уроке нарисованы кодом (подписаны «Схема»), стоковых фото нет.
