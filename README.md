# Нейро Обуч — школа нейросетей

Продающий сайт-презентация онлайн-школы нейросетей: курсы, бесплатный урок, аудио, гайды, лента «Новое каждый день».

**Сайт:** https://avtomaster24bot-lab.github.io/neuro-obuch/

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Главная: оффер, аудио-презентация, курсы, лента, лид-магниты, отзывы (макет), FAQ |
| `kursy/` | Каталог и тарифы; `kursy/<курс>/` — страница каждого курса (7 штук) |
| `urok/formula-prompta/` | Бесплатный пробный урок со схемами и аудио |
| `novoe/` | Вся лента «Новое каждый день» |
| `gaydy/` | Бесплатные гайды (HTML + PDF): «Карта нейросетей 2026», «30 промптов» |
| `config.js` | **Все ссылки**: Telegram-канал, бот, оплата, соцсети, кодовое слово |
| `data/feed.json` | Лента «Новое каждый день» |
| `assets/` | Стили, скрипты, картинки, аудио |
| `_src/` | Исходники: `data.py` (курсы, цены, FAQ), `build.py` (сборка страниц), `svg.py` (схемы), `audio/*.txt` (тексты озвучки), `tools.py` (PDF и скриншоты) |

## Как добавить новинку в «Новое каждый день»

Откройте `data/feed.json` и добавьте объект **в начало** массива `items` (лента сортируется по дате, сборка не нужна):

```json
{
  "date": "2026-11-24",
  "title": "Короткий заголовок новинки",
  "tag": "Видео",
  "text": "Что появилось — 2–3 предложения.",
  "how": "Как применить у себя.",
  "source_name": "Блог компании",
  "source_url": "https://ссылка-на-первоисточник",
  "video_url": "https://youtube.com/shorts/... (необязательно)",
  "region": "Ограничения по странам (необязательно)"
}
```

Теги: `Текст`, `Картинки`, `Видео`, `Голос`, `Бизнес`, `Агенты`, `Код`. Если указать `video_url`, на карточке появится кнопка «Смотреть видео» — так ежедневные ролики из YouTube/Shorts/Rutube/VK попадают на сайт. Всегда указывайте первоисточник.

Можно править прямо на GitHub: открыть файл → карандаш ✏️ → Commit. Через 1–2 минуты сайт обновится.

## Как поменять ссылки Telegram и оплаты

Всё в одном файле `config.js`:

- `TELEGRAM_CHANNEL_URL` — канал (сейчас https://t.me/PostFlowFactory);
- `TELEGRAM_BOT_URL` — бот, которому пишут кодовое слово (**заглушка** `REPLACE_BOT`);
- `KEYWORD` — кодовое слово (сейчас «ИИ»);
- `PAY.default` — общая ссылка на оплату (Tribute и т. п.), **заглушка**; можно задать свою ссылку для каждого курса (`s-nulya`, `kontent`, `kartinki`, `video`, `golos`, `biznes`, `ii-pomoshchnik`, `bundle`);
- `YOUTUBE_URL`, `INSTAGRAM_URL`, `TIKTOK_URL`, `VK_URL` — пустые иконки скрыты;
- `CONTACT_URL` — «Написать нам» (**заглушка**).

Пока в ссылке есть `REPLACE`, кнопка не уводит на несуществующую страницу, а показывает посетителю «Ссылка скоро появится».

## Как поменять курсы, цены, тексты

1. Правите `_src/data.py` (цены — поле `price`, сейчас **предварительные**).
2. Запускаете `python3 _src/build.py` — страницы пересоберутся.
3. Аудио: правите `_src/audio/*.txt`, затем
   `edge-tts --voice ru-RU-SvetlanaNeural -f _src/audio/prezentaciya.txt --write-media assets/audio/prezentaciya.mp3`
4. PDF гайдов: `python3 _src/tools.py pdf` (нужен `pip install playwright && playwright install chromium`).

## Что осталось заполнить

- Ссылка на бота с кодовым словом, ссылка оплаты, контакт — в `config.js`.
- Цены курсов — предварительные.
- Отзывы — сейчас честный макет с пометкой «ПРИМЕР»; замените настоящими после первого потока.
- Оферта и условия возврата.

Картинки курсов сгенерированы ИИ, схемы в уроке нарисованы кодом (подписаны «Схема»), стоковых фото нет.
